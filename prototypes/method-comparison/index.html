La stessa schermata, quattro modi di produrla

Il soggetto è la preparazione di «Ritorno a Borgo Mulino» con la colonna delle persone: prosa, conflitti, schede dense. Scegli il metodo, non il marchio.

  • A · studio dentro l'applicazione (JinjaX reale)

    Componenti, token, font, dialoghi e htmx veri. Richiede il backend di sviluppo.

    Apri A

  • B · output in stile Agent-Native Design (Tailwind + Alpine)

    HTML autonomo, utility class, dati finti. Emulazione del formato, non il prodotto.

    Apri B

  • C · artboard vettoriale (stile Penpot / OpenPencil)

    Geometria e gerarchia senza token, font o comportamento. Emulazione di ciò che il file contiene.

    Apri C

  • D · WebMCP reale su una pagina di prova

    Polyfill @mcp-b/global installato in locale; le azioni sono strumenti tipizzati.

    Apri D
