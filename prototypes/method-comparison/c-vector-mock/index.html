Metodo C · artboard vettoriale (emulazione di un file Penpot / OpenPencil)

Geometria e gerarchia senza token, font, componenti o comportamento. Un file di questo tipo va tradotto in JinjaX: qui è disegnato ciò che il file conterrebbe, non il file stesso.

Nessun font del progetto, nessun token, nessuna variante di componente: il file contiene rettangoli e misure. Ciò che manca qui — dialoghi, focus, stato dei tracciati, htmx, dipendenze CSS — non è un dettaglio implementativo, è la parte che nelle prove precedenti ha prodotto i difetti reali. Misure annotate: distanza fra colonne 32, margine interno scheda 20.
