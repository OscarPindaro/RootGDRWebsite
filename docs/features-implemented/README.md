# Implemented features

One short document per feature that exists. Each says **what it does**, at the
level someone using it cares about, and **how it is built**, at the level the
next person touching it cares about.

This is not a changelog: no lists of tests run, no migration logs — unless the
test or the migration *was* the point of the feature. Keep it readable by a
human in a couple of minutes.

Template:

```markdown
# <Feature>

<One sentence: what it is for.>

## What it does

## How it is built

## Notes and limits
```
