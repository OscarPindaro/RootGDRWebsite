# Implemented features

One short document per feature that exists. Each says **what it does**, **how it
is built**, and its **limits**. This is not a changelog or a test log.

Template:

```markdown
# <Feature>

<One sentence: what it is for.>

## What it does

## How it is built

## Used by          <!-- only when it has real callers -->

## Limits
```
