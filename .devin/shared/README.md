# Shared collaboration standards

The technical conventions, engineering guidance, review scale and hybrid UI
reference are copied from the supplied `ai-utils-main.zip`, together with the
stack preflight scripts and their fixture suite. The source license restricts
use to Circeus and authorized collaborators; see `LICENSE`.

These references support explicitly invoked maintenance and observability
skills. They are not always-on instructions and do not authorize migration of
the hosting repository. Report conflicts with repository rules before proposing
changes. Some upstream names remain placeholders; do not substitute guessed
repositories, credentials or infrastructure.

The local development-loop, writing and documentation references route to the
ported workflow. They preserve plain-prose questions, optional chronicles,
existing documentation formats and explicit delegation permissions.

Technical examples are reference material. Their private dependencies and live
telemetry paths are not installed or verified by copying the documents.
