# Writing

Follow the repository's communication rules and the
[ported workflow](../skills/using-development-skills/SKILL.md).
Use concise, calm, precise language. State results, reasons, compatibility,
verification and uncertainty. Preserve names, commands, constraints and other
details needed to continue safely.

Ask questions in plain prose. Avoid decorative labels, forced contrasts,
repetition and unnecessary enthusiasm. Keep the established file language;
source and documentation in this repository are English.
