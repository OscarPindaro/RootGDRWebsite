# Documentation

Follow existing repository formats, locations and metadata.
Use the [maintenance procedure](../skills/align-docs/SKILL.md) for stale claims,
conflicting guidance and approved structural changes.

Chronicles and dedicated plan directories are optional. Use existing
specifications, feature manuals and decision records rather than creating a
parallel system. Keep live task status in the repository's configured tracker.
Do not add a new frontmatter schema to existing documents as a side effect of
using a technical reference.
