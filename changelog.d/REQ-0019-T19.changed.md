Button, Pill and Grid now reject a value outside their recorded vocabulary when the component renders: an invented Button or Pill variant, an unknown Button size, `Grid` `columns=4`, an absent spacing step or an unknown minimum raises `ComponentOptionError` with the component, argument and rejected value instead of emitting a class no stylesheet matches. The accepted values, including Button `lg`/`xl` and the reserved `shape` no-op, still render, and native HTML attributes keep passing through untouched.
